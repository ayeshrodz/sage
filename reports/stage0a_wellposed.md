# Stage 0a: economics of a given library (well-posed tasks)

Generated by `experiments/stage0a.py --well-posed` at git `e20df17` (generator 0a.1, Python 3.11.15). 40 dev tasks per verifier strength, budget 20,000 candidate programs per task, seed 0.
28 base instructions, 13 planted entries, distractors: random stack-balanced macros of 2-5 instructions with distinct behaviour on probe inputs.

Guides are *simulated* (they know which tokens the target uses): uniform = no guide; margin = fixed 100x preference for relevant tokens; mass = relevant tokens keep 90% of probability. Routing = 32 multiply-adds per token (brute-force scoring).
`correct` = the found program matches the hidden target on every held-out query of the stratum.
Costs are element operations (entities and edges touched); candidates are censored at the budget (≥).
